# 2. CORE IDENTITY

## Project

AETHER

## Tagline

**Invisible Light. Visible Impact.**

## Core idea

AETHER explores how architectural glass can become an active renewable-energy surface rather than remaining purely passive.

The concept is based on a transparent luminescent solar concentrator architecture:

**Sunlight → selective absorption → luminescent re-emission → optical guidance → edge photovoltaic conversion → electricity**

The main transparent area remains largely free of conventional photovoltaic cells.

Photovoltaic cells are concentrated around the perimeter.

The result is intended to combine:

**architectural transparency + optical energy collection + photovoltaic conversion**

AETHER is NOT intended to replace conventional rooftop solar.

It addresses a different question:

**What if surfaces that already need to be transparent could also contribute to energy generation?**
